This is a short readme, explaining why this repo has been neglected.

I did this tutorial over a year ago, after finding it on build-your-own.org

I was very interested in getting better at my C++ and software skills at the time

But unfortunately, I did not keep up with pushing my progress to GitHub, as I
really thought there was a 0% chance that I would work in software, or that 
anyone would even look at this!

Anyways, this came up in an interview today, so I figured I might as well push
the finished project. It was a great experience, but no amazing technical feat

The tutorial gives you all of the code, so I pretty much just typed it out word
for word. But I found a lot of value in digging into all of the small things
that I got the opportunity to learn, like sockets, hash maps, TCP/IP, system calls,
and so much more. 

So it really wasn't the destination, but the friends we made along the way
that I found the real value in!!!
